Project Compass

职业规划项目总览

它把“我适合什么岗位、还差什么、下一步学什么”变成一条可解释的操作链。

核心链路

岗位样本 → 形成 6 个计算机类岗位画像
学生手填或上传简历 → 形成能力画像
人工确认 → 才允许进入匹配和建议
程序匹配 → 计算满足、差距、待确认和推荐
AI 建议 → 根据程序算出的事实生成学习方向

四个主要区域

  • 岗位浏览：看岗位画像、要求、证据和职业路径。
  • 我的能力：填写专业、技能、证书、素质和证据，也可以导入简历。
  • 职业路径：查看岗位之间的晋升和换岗参考。
  • 匹配与建议：查看匹配分、差距、筛选结果和职业建议。
记忆句：程序负责算清楚“现在匹配什么”，AI 负责解释“接下来怎么学”。
