# 项目使用全过程

本文按真实界面和当前代码（算法版本 matching-2.2，见 [ADR 0002](adr/0002-mentioned-skills-without-confirmation-gate.md)），记录从安装启动到整理资料、查看匹配、采取行动并保存本机进度的完整过程。应用运行在本机，面向演示与自我探索；没有账号或数据库，个人资料只保存在当前浏览器（若启用自动保存），不会上传到本项目服务端。

## 流程总览

~~~mermaid
flowchart TD
    A[安装依赖并启动本机服务] --> B[打开页面，在新手教程中选择入口]
    B --> C{先看岗位或先整理资料}
    C -->|先看岗位| D[浏览岗位并设为目标]
    C -->|整理资料| E{准备资料}
    D --> E
    E -->|手动录入| F[填写背景并添加技能、证书、素质]
    E -->|导入简历| G[上传简历，提取结果直接填入资料]
    F --> H[按需修改或删除条目]
    G --> H
    H --> I[可选：生成个人分析报告]
    H --> J[计算匹配并查看岗位推荐]
    I --> J
    J --> K[可选：生成岗位建议并复制或导出 TXT]
    D --> M[随时查看职业成长路径]
    J --> M
~~~

简历解析、个人分析报告和岗位建议需要配置真实模型服务。没有模型配置时，仍可浏览岗位和路径，也可以手动填写资料、查看确定性匹配结果；简历解析与 AI 文字建议暂不可用。

## 1. 安装并启动

在 Windows PowerShell 中进入项目根目录。首次使用需要 Python 3.12、Node.js 20+、npm 和网络连接：

~~~powershell
./install.ps1
Copy-Item .env.example .env
~~~

如果准备使用真实模型，在本机编辑 <code>.env</code>，填写可信服务商提供的 <code>LLM_BASE_URL</code>、<code>LLM_MODEL</code> 和 <code>LLM_API_KEY</code>。示例文件里的域名与密钥只是占位值。不要把密钥放进聊天或提交到版本库。也可以先不配置模型，直接启动手动匹配流程。

~~~powershell
./start.ps1
~~~

浏览器打开 <code>http://127.0.0.1:8000</code>。若端口被占用，可运行 <code>./start.ps1 -Port 8001</code>，再打开 <code>http://127.0.0.1:8001</code>。服务只绑定本机回环地址。完成使用后，在运行服务的 PowerShell 窗口按 <code>Ctrl+C</code> 停止。

之后再次使用通常只需启动脚本，无需重新安装依赖。修改前端代码后，先在 <code>frontend</code> 目录执行 <code>npm.cmd run build</code>，再重启服务。

## 2. 进入职业探索

首次打开会显示 **新手教程**。可以选择 **我有简历**（从简历开始）、**我没有简历**（手动建立档案）或 **我先看看岗位**，也可以直接关闭教程。之后可随时点击顶部的 **新手教程** 重新打开。

主导航包含四个区域：

- **职业探索**：搜索和查看岗位画像。
- **简历与个人报告**：导入简历或手动填写资料，整理技能并生成个人分析报告。
- **匹配报告**：计算岗位匹配、设置筛选条件、生成和导出建议。
- **成长路径**：查看纵向晋升和横向转岗路线。

主导航下方的流程栏显示四步状态：导入或填写资料 → 个人分析报告 → 岗位匹配 → 行动建议，并提供当前可执行的下一步。目标岗位不是开始的前提；四个页面可自由切换，浏览器前进和后退也会切换当前页面。

首次使用时，新手教程会询问是否在这台浏览器自动保存（**自动保存** 或 **本次不保存**），之后可在顶部 **设置** 中修改。启用后，已整理的简历资料、目标岗位、当前页面和已选成长路径会随操作自动保存；关闭后仍可继续当前会话，但本次不读取旧草稿。

顶部的 **AI 模型配置** 可在应用内选择 DeepSeek 或 OpenAI 兼容接口，填写地址、模型、适配器和密钥，保存后点击 **测试连接**。测试只发送一条不含个人资料的短请求。通过界面保存的配置只作用于当前运行中的服务进程；若希望服务重启后仍保留，请把配置写入本机 <code>.env</code>。

## 3. 浏览岗位并选择目标

在 **职业探索** 页面，可以按岗位名称、方向或技能关键词搜索。点击岗位卡片打开详情，查看岗位简介、核心技能、证书、通用素质、优先项和历史招聘样本；岗位详情也会显示要求等级的整理依据与样本引用。点击 **设为目标岗位**，即可把该岗位设为个人意向岗位。

岗位可以先选，也可以稍后再选。点击 **设为目标岗位** 后会进入 **简历与个人报告** 继续整理。更换目标岗位会让已有匹配和报告过期；请刷新匹配后再生成新建议。筛选条件只改变岗位推荐，不改变资料。

岗位画像来自项目收集的赛题招聘样本，目标是整理初级能力基线。样本不保证仍在招聘，画像也不代表所有雇主的统一硬性要求。

## 4. 导入或填写资料

进入 **简历与个人报告**。页面分三步：导入简历、整理能力、个人分析报告。第 1 步可在 **导入现有简历** 与 **手动录入资料** 之间切换，两种方式可以配合使用。

### 导入简历

在 **导入现有简历** 中点击上传区域，选择文本型 PDF、DOCX 或 TXT 文件。单文件最大 5 MB，提取文字最多 30,000 字符，PDF 最多 50 页；扫描图片、加密、损坏或没有足够可提取文字的文件不受支持，也不会进行 OCR。仓库中的 <code>samples/虚构简历.pdf</code>、<code>.docx</code> 和 <code>.txt</code> 是虚构演示样例。

解析会把简历文字交给当前配置的模型，提取专业、经历、技能、证书和通用素质，并**直接填入**资料，不需要逐项接受或确认。重新导入只替换上一次简历导入的条目，手动补充的专业、经历和能力会保留。解析失败时，已填写内容保持不变，可以重试或改为手动录入。

识别到的姓名显示在 **简历姓名** 中，可以核对或修改；它只保存在当前会话，不参与匹配计算，也不写入报告或本机草稿（[ADR 0001](adr/0001-resume-name-session-boundary.md)）。

上传前请删去不必要的身份信息。应用不保存简历文件或正文日志，但模型处理会把相关输入发送给你配置的服务商。

### 手动录入

切换到 **手动录入资料**，填写专业、意向城市和项目／实习经历。已导入的简历内容不会被清空。

## 5. 整理技能信息

第 2 步 **整理技能信息** 列出当前资料中的技能标签、证书和通用素质。每个条目标注 **简历提取** 或 **手动补充**，可点击 **修改** 或 **删除**；发现遗漏时在对应区域输入后添加。输入框会提示岗位标签字典中的名称和别名；不在字典中的标签会标记为 **未入字典**，可能无法与岗位要求对应，优先使用字典中的规范标签。

资料中提及的条目会直接参与匹配，不需要填写熟练度，也不需要提交证据或点击确认。简历未提及的能力不等于不具备；提及也不代表已被核实，请只保留与真实经历相符的内容。

第 3 步 **个人分析** 是可选的：点击 **生成个人分析报告**，模型会根据当前资料整理技能清单、可展示的优势和下一步提升。它不影响匹配分数；没有模型配置时可以跳过，直接点击 **查看岗位匹配**。资料修改后，可重新生成个人报告或刷新岗位匹配。

## 6. 查看匹配与筛选推荐

进入 **匹配报告**，系统会根据当前资料计算推荐。即使没有目标岗位，也可以查看岗位推荐；设定目标后，目标岗位即使不在前五个推荐中也会单独计算并展示。页面依次展示岗位匹配概览、技能与岗位维度、岗位要求与当前资料、AI 建议和其他高匹配岗位。所有结果只根据当前资料计算，未提及不代表不具备。

- **基础匹配度**统计当前资料中已提及的必需要求占全部必需要求的比例，不推断熟练度。
- **增强匹配度**在此基础上考虑关联技能提供的基础（最多 0.25，不叠加），不代表已掌握全部岗位技能，也不改变基础分。证书和通用素质按是否提及计算。
- **优先项**只作补充建议，不计入基础分或增强分。

岗位要求按必需项优先排列，每项显示 **资料中已出现** 或 **资料未提及**。未提及的项目可以点击 **补充资料 →** 回到资料页按实际情况补充。

展开 **调整岗位筛选条件**，可以设置城市、薪资下限／上限、按月或按天计薪、必须包含的技能，并选择按基础分或增强分排序，然后点击 **应用筛选**。多个技能条件要求岗位同时包含所有指定标签。薪资和城市筛选基于岗位关联的招聘样本；月薪和日薪不会互相换算。未设置薪资范围时保留薪资未知的样本，启用薪资范围后未知或计薪周期不同的样本不能满足该条件。

系统最多展示 5 个符合条件的推荐岗位。点击其他岗位卡片即可切换当前分析对象；切换后旧建议会清除，需要为新岗位重新生成。资料修改、目标岗位切换或服务端数据与算法版本变化后，页面会提示原因，点击 **刷新匹配结果** 即可。

## 7. 生成并导出职业建议

选定要分析的岗位后，点击 **生成岗位建议**。后端会按当前资料重新计算分数和匹配事实；AI 只负责生成契合度评价、学习方向和学习建议，不参与评分。模型没有配置、网络不可用或返回内容不符合要求时，页面会显示错误，可修正配置后重试。

检查建议与自身情况是否相符后，可以点击 **复制报告** 或 **导出 TXT**。两种操作使用服务端返回的同一份报告正文，报告中区分“资料已提及”和“资料未提及（不代表不具备）”。资料、目标岗位或服务端版本改变后，旧报告会标记过期并禁止复制或导出；刷新匹配结果后再生成新建议。

建议用于辅助规划，不保证录用、薪资或岗位转换。历史样本也不应当作当前招聘信息。

## 8. 查看成长路径并结束使用

进入 **成长路径**，默认聚焦目标岗位（如果没有目标岗位则使用可用路径）；你手动切换后会沿用自己的选择。点击阶段卡片或路线可查看可迁移能力、待补差距和建议活动。点击 **保存当前路径** 会保存当前聚焦岗位及选中的路线，并显示保存时间；需要时可以清除已保存路径。

### 本机草稿、关闭与清除

启用自动保存后，以下信息保存在当前浏览器的本机存储中，并在刷新或重新打开页面时恢复：已整理的资料、目标岗位、当前流程页面，以及已保存的成长路径。草稿带有格式版本；若损坏或版本不兼容，页面会提示无法恢复并从空白会话继续。

本机草稿**不包含**简历姓名、原始简历文件、AI 报告或模型密钥。自动保存开关可随时关闭；关闭后本次不会读取旧草稿，已有草稿会保留到你手动清除。浏览器存储不可用或写入失败时，页面会提示原因，当前会话仍可继续使用。

在 **设置** 中点击 **清除本机草稿并重置流程** 会删除当前浏览器中的草稿，并重置资料、流程位置和保存的成长路径；不会清除服务端或模型配置。需要保留职业建议时，请先点击 **导出 TXT**。完成使用后，在服务终端按 <code>Ctrl+C</code> 停止服务。

## 故障时怎么继续

| 现象 | 处理方法 |
|---|---|
| 页面打不开或显示无法连接后端 | 检查 PowerShell 中的服务是否仍在运行，并使用启动时对应的端口访问。 |
| 岗位列表或详情加载失败 | 点击页面的重新加载；若持续失败，重启本地服务并检查终端错误。 |
| 简历解析、个人报告或建议提示模型未配置 | 在 **AI 模型配置** 中填写并保存后测试，或在本机 <code>.env</code> 配置并重启服务。手动匹配不要求模型。 |
| 简历无法读取 | 确认文件是可复制文字的 PDF、DOCX 或 TXT，未加密且没有超过大小、页数和文字限制；也可手动填写。 |
| 匹配或报告提示已过期 | 按页面说明的原因点击 **刷新匹配结果**，再生成新建议。 |
| 关闭自动保存后看不到旧资料 | 自动保存关闭时不会读取旧草稿；重新启用即可恢复，或检查是否已清除草稿。 |
| 本机草稿无法保存或恢复 | 确认浏览器允许本地存储；存储不可用时可继续当前会话，但刷新后无法恢复。 |
| 自定义能力没有计入岗位匹配 | 把 **未入字典** 的标签改为 <code>/api/tags</code> 中的字典标签或别名。 |
