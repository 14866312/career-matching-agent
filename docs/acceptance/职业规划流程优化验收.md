## 验收范围

流程按“简历分析 → 按需修正技能 → 个人分析报告 → 岗位匹配 → 针对性建议”验收。简历 PDF / DOCX / TXT 上传后自动合并到可编辑档案，用户可以继续补充专业、技能、证书、通用素质和经历；流程中不再要求逐项确认技能，也不再展示独立能力画像或雷达图。

浏览器主套件覆盖本机草稿恢复、关闭和清除，姓名与简历文件不写入草稿，无目标岗位时建档和推荐，自动合并简历及延迟响应保护，目标岗位、档案内容和服务端版本变化后的结果失效，推荐筛选、目标切换、报告复制与 TXT 导出，成长路径保存，以及窄屏布局和键盘激活流程导航。

端到端服务仅模拟模型 JSON 输出；岗位、匹配、报告、文件解析和其余应用流程均通过真实应用接口验证，不调用真实模型服务。
