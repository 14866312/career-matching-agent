独立审查另发现等级说明与样本日期子元素仍有显式 11px 字号，原父元素断言未覆盖它们。新增岗位详情 mono 子元素断言后真实失败，窄屏补为 12px 后 UI 回归通过；当时重新构建并完成 18 次零违规 axe 扫描，岗位详情截图已更新。最小字号由 UI 回归验证，不冒充 axe 的检查范围。资料与路径的底部操作区断言共用同一检查。

smoke 回归共 12 项通过；修复前复现 5 项失败。增强分、两个展示分或输入版本等五项事实任一漂移会使 smoke 退出 1；两边共同缺失必填事实也不能通过。`name_edit` 标记 `not_applicable`，前端姓名编辑与刷新由浏览器验收，API 脚本不冒充该证据。浏览器在无姓名简历导入完成后填写会话姓名，明确断言刷新前姓名非空、草稿不含姓名，刷新后姓名为空且其他资料与路径恢复；旧测试顺序在新增非空断言下真实失败，修正后的 17 个场景全部通过。
