## 数据与样例复现

顺序执行两次 `scripts/build_data.py`，生成岗位 JSON 与审核文档的哈希相同，原始 XLS 的哈希不变，且与执行前基线相同；当前哈希见 [数据可复现性](数据可复现性.json)。`competition/`、生成数据与已提交样例没有差异。

在忽略的本机验证目录运行 `scripts/make_samples.py --include-pdf`，TXT、DOCX、PDF 均可由生产提取器读取，五份学生 JSON 通过 StudentProfile 校验且不包含 name 字段。PDF 工具依赖仍在 `requirements.samples.txt`，未加入应用运行依赖。

## 真实模型闸门

通过 `./start.ps1 -Port 8012` 启动生产入口。2026-10-01 16:54:48 +08:00 独立检查 `/api/health` 返回 ok、career-1.3、matching-2.2，llm_configured 为 false。

2026-10-01 17:00:31 +08:00 运行 `scripts/smoke_live.py --url http://127.0.0.1:8012`，实际退出 2、输出 not_verified：本机无 .env，三个模型配置均未提供。CLI 在本地配置闸门停止，未连接应用，也未调用供应商；独立 health 检查不能写成 CLI 已完成 health 步骤。详见 [真实模型验收](真实模型验收.md)。

只需用户在本机配置已选定服务的 LLM_BASE_URL、LLM_MODEL、LLM_API_KEY（必要时 LLM_ADAPTER），重启生产服务再运行 smoke；退出 0 才能记录适用 API 检查通过。不得把 mock 回归或缺配置的退出 2 当成成功调用。
