## 3. 实测记录（2026-09-17）

| 模型 | 探针结论 |
| --- | --- |
| Kimi/glm-5.3 | 通过，正常返回 |
| Kimi/kimi-k3 | 通过，正常返回 |
| volcengine-agent-plan/glm-5.3-flash | 通过，正常返回 |
| deepseek/deepseek-flash | 通过，正常返回 |
| pixel 系列五个模型 | 全部失败：上游流在返回途中断开（upstream stream ended without a terminal signal），未能产出一个 token。该 provider 随后已从模型池中消失。 |
| gpt-5.6-sol | 失败：not supported when using Codex with a ChatGPT account |
| gpt-5.6-terra | 探针可通过，但未出现在模型选择器中（visibility 为 hide），暂不纳入分配 |

结论：当前只有上表前四个模型可以真正驱动子代理，分配表按这四个模型设计。
pixel 系列一旦恢复可用，需要重新评测后再调整，不要把未验证的模型写进配置。

## 4. 维护方式

改模型只需改对应 TOML 的 model 行，保留 model_reasoning_effort。改完后应当用一次最小探针确认该路线真能返回结果，
再派发实际任务；探针失败要如实记录，不要把失败通道当作可用资源。
