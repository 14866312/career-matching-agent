# 简历候选审核与匹配项直达档案

Status: ready-for-human

## Scope

把解析结果直接合并到可编辑资料，保留既有非空档案值，允许用户修改或删除重复和新增能力；姓名也只在会话内使用。匹配结果按必需项优先展示，资料未提及项可直达资料编辑、学习建议或成长路径。

## Acceptance

- 简历解析成功后直接填入资料；解析失败不修改已有档案。
- 用户可以修改或删除解析出的条目，matching-2.2 下正等级的资料已提及条目直接参与匹配。
- 同标签合并不覆盖既有非空内容；confirmed 仅为兼容字段。
- 简历姓名、文件和候选都不写入本机草稿。
- 匹配行说明其状态原因并提供可键盘操作的相应跳转。
