# 简历候选审核与匹配项直达档案

Status: ready-for-agent

## Scope

把解析结果放入仅存内存的逐项接受/跳过审核清单，经用户确认后才合并。保留既有非空档案值，合并重复能力，不自动确认新增能力；姓名也只在会话内，经核对后使用。匹配差距按必需项优先展示，待确认/缺证据直达并展开对应档案证据编辑，未填写项聚焦对应能力输入，已确认差距可进入学习建议或成长路径。

## Acceptance

- 简历解析成功不立即修改档案；解析失败不修改档案。
- 所有候选均需逐项决定，确认合并后只有接受项写入。
- 同标签合并不覆盖既有非空内容；新增能力处于未确认状态。
- 简历姓名、文件和候选都不写入本机草稿。
- 匹配行说明其状态原因并提供可键盘操作的相应跳转。
