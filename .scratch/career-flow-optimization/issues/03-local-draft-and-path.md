# 本机自动保存与成长路径保存

Status: ready-for-human

## Scope

新增带版本、可验证的浏览器草稿存取模块；保存档案、流程页面、选中成长路径，不保存姓名、简历候选、文件、报告或密钥。提供首次使用说明、自动保存开关、草稿状态/时间和清除入口。异常时内存流程继续工作。路径初始聚焦目标岗位，用户选择优先于后续目标变更，并真实保存所选路线。

## Acceptance

- 刷新恢复约定字段；清除后重置档案、流程位置、所选路径。
- 格式损坏/版本不兼容/读写异常有提示，不阻塞空白或内存会话。
- 自动保存关闭后不再写入；姓名、候选、报告始终不入草稿。
- 路径焦点和选择在刷新后恢复，可清除。
