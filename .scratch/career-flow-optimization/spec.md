# 职业规划应用端到端流程优化

Status: ready-for-human

## Goal

保留职业探索、能力档案、匹配报告、成长路径四个页面，增加可自由跳转的全局进度引导；允许先建档后浏览推荐。让目标岗位变更、档案编辑、匹配和报告的失效关系清晰；简历解析结果直接进入可编辑资料，用户可以按需修改或删除；在浏览器本机保存约定的草稿字段，并真实保存所选成长路径。

## Product constraints

- 除已由 ADR 0002 记录的 matching-2.2 口径外，不新增后端 API 或额外改变匹配分数和 AI 建议规则；无需模型配置仍能手动建档并查看岗位推荐。
- 单独变更目标岗位或编辑资料内容时，保留资料本身并递增输入版本，使匹配和报告失效；筛选仅影响推荐结果。
- 简历解析结果直接填入资料，已有手动填写的专业、经历和能力保留；用户可以在资料页修改或删除解析条目。解析出的姓名单独保存在当前会话，不并入 StudentProfile。
- matching-2.2 下，资料中等级大于0的已提及条目直接参与匹配；confirmed 和 evidence 仅为兼容和核对字段，不是匹配门槛。
- 本机草稿只保存档案、目标岗位（档案字段）、流程页面和选中的成长路径。不保存姓名、简历文件或候选、分析/报告、模型密钥。
- 草稿损坏/不兼容时提示并开始空白会话；存储失败时保留内存流程并提示；清除草稿重置会话档案、位置和保存路径。
- 新手教程与首次本机保存选择在同一个弹窗内完成：保存选择未完成前不能关闭，完成保存选择后用户可完成或跳过教程；顶部入口可再次打开。教程状态只保存版本化的完成/跳过标记和时间，不写入业务草稿。

## Acceptance

1. 导航下始终显示四阶段进度和上下文下一步；未选目标不阻塞建档或推荐；历史前进/后退仍可用。
2. 目标变更使旧匹配、报告不可生成/导出；画像内容编辑也会使结果过期；状态按资料未填写、资料已提及、资料未提及表达，不把未提及解释为不具备。
3. 简历解析结果直接进入可编辑资料；重复项保留既有非空值，用户可修改或删除；失败不修改已有档案。
4. 匹配待办优先显示必需项，能跳转并聚焦对应档案标签编辑；资料未提及的项目能通往补充资料、建议或路径。
5. 草稿恢复、关闭自动保存、清除、损坏、版本不兼容和存储异常均有明确行为；解析后已合并的资料可随草稿恢复，姓名和报告不恢复。
6. 成长路径以目标岗位为初始焦点，用户切换后可保存和恢复焦点；显示已保存和清除入口。
7. 运行前端单测、构建、浏览器端到端测试、后端回归；核对窄屏与键盘操作。
8. 首次进入可选择“我有简历”“我没有简历”“我先看看岗位”作为起点；教程解释岗位可跳过、简历结果可修改、资料提及与匹配、报告和成长路径，并支持跳过、完成、Escape 和 Tab 焦点循环。

## Implementation status

当前代码已实现上述流程、matching-2.2 评分口径、姓名会话隔离和本机草稿边界。自动化 mock 回归与后端/前端测试已通过；真实模型验收仍需本机模型配置，结果记录在 docs/acceptance/真实模型验收.md。
