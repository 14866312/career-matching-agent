## 新增亮色 / 护眼主题

- 原设计是**纯灰阶深色**主题（12 个 CSS 文件、约 575 处颜色，全部 R=G=B），无图片、无 `url()`。
  因此亮色主题用**亮度反演 + 暖色调映射**机械生成，数学上无损，不会漏改留下黑斑。
- `scripts/make_light_theme.py`（入库，遵循 `scripts/build_data.py` 的 `ROOT = parents[1]` 约定）
  → 生成 `frontend/src/styles/theme-light.css`（约 1730 行，仅含颜色声明，全部作用域在
  `[data-theme="light"]` 下，故深色主题**由构造保证**不受影响）。
- 反演语义会出错的地方单独放 `frontend/src/styles/theme-light-patch.css`（手工维护，生成文件不覆盖它）：
  模态遮罩需保持深色、toast 需保持深色、`color-scheme: light`、`body` 底色、base.css 少数 token。
- 两者都在 `styles.css` **最后**导入。
- `lib/theme.ts`：`Theme = 'dark' | 'light'`，默认 **light**；存储键 `career-appearance`；

## 验证手段（可复用）

- 本机无 Playwright 依赖，改用 **Edge headless + DevTools Protocol**：
  `tmp/shot.mjs <url> <out.png> [initScript] [postScript] [w] [h] [full|viewport]`。
  `initScript` 经 `Page.addScriptToEvaluateOnNewDocument` 在页面脚本前注入，
